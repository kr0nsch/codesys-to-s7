# codesys-to-s7

Перенос проектов CODESYS 3.5 (ОВЕН ПЛК2xx, REGUL и др.) в Siemens S7-1200/1500 (TIA Portal):
внешние исходники SCL/DB/UDT, сети LAD/FBD в SimaticML, таблица тегов, тела OB и отчёт о переносе
с классом каждой конструкции. Эквивалентность проверяется обратным переводом через s7-to-codesys.

Проект в разработке; описание и быстрый старт появятся вместе с первым выпуском.
