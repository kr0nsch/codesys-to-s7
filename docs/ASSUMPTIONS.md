# Допущения и то, что не проверено

Каждое допущение помечено уровнем: [H] — документация, XSD, экспорт или прогон на этой машине;
[M] — презентация, чужой код, вывод; [L] — предположение. Что проверено прогоном — в `PROBES.md` и
`TEST_REPORT.md`.

## Не проверено совсем

| № | Допущение | Уровень | Чем закрыто |
|---|---|---|---|
| A1 | TIA Portal V19/V21 принимает наши внешние исходники `.scl/.db/.udt` | [M] | разбор s7conv без RawStmt/RawDecl, форма по корпусу s7-to-codesys и экспортам; процедура — `HARDWARE_VALIDATION.md` |
| A2 | Openness импортирует наш SimaticML FlgNet | [M] | XSD V19/V21 по фрагментам, свой валидатор, структура эталонного набора (происхождение [M]); форма прыжка `Jump` + `Access Scope=Label` — [L], эталона нет |
| A3 | Таблица тегов `.xlsx` импортируется через GUI | [M] | колонки по R§2.5 |
| A4 | Поведение S7 совпадает с поведением ST′ в CODESYS | [M] | кольцо доказывает согласованность c2s7 и s7conv, не поведение S7; verify-конструкции вынесены в `probe/` |
| A5 | `MultilingualText` с культурой en-US примет любой проект TIA | [L] | en-US есть в стандартной установке; иначе — заменить культуру в XML |
| A6 | `AutoNumber = true` + порядковый `Number` не конфликтует при импорте | [L] | номер можно сменить в TIA |

## Проверено частично

| № | Допущение | Уровень | Что проверено |
|---|---|---|---|
| B1 | Порядок цикла SFC CODESYS (справка) | [H] | трассы Control Win двух SFC корпуса совпали с автоматом c2s7 (1303 цикла); время шага идёт с цикла активирующего перехода — уточнено по трассе |
| B2 | IEC-действие исполняется ещё раз после деактивации (последний вызов), в том числе с квалификатором P | [H] | трасса PRG_Backwash: ActDrain +1 после ухода из шага, ActCount — дважды |
| B3 | entry/exit-действия SFC | [L] | в CODESYS 3.5.17 из PLCopen не импортируются (M0: N); автомат их поддерживает по справке, на трассе не проверены |
| B4 | IL | [M] | CODESYS IL из PLCopen не импортирует (M0: N); IL → ST проверен на своих сценариях в c2s7.sim |
| B5 | EN/ENO | [L] | боксы с EN/ENO CODESYS из PLCopen не принимает (M0: N); ENO → C2S7-GFX-ENO, вызов под `IF EN` |
| B6 | Таймер S7-1200 обновляет Q/ET при чтении членов | [H] документ | S7-1200 Manual 04/2012 §7.2; c2s7 переписывает идиому на выход вызова; на S7-1500 — пробник |
| B7 | Округление REAL_TO_INT на половине в S7 | [L] | источники противоречивы → пробник P01 |
| B8 | LIMIT при MN > MX в S7 | [M] | по сведениям s7-to-codesys S7 даёт IN и ENO = FALSE → пробник P02 |

## Решения, принятые вместо данных

- Модель трудозатрат не калибрована: минуты на правило задал автор по описанию правила; результат
  подписан «модель, не калибрована».
- CFC → FBD, GRAPH, SD, ООП, CodesysCompat кроме CDS_SR/RS, профили V15.1–V18 — P1, в 0.1.0 не
  входят (`ROADMAP.md`); при запросе выдаётся находка и автомат/SCL.
- Блок с графикой вне подмножества FlgNet целиком уходит в SCL (C2S7-GFX-SCL), а не по сетям.
